Retrieval-Augmented Generation · TREC RAG 2026

From Question to Grounded Answer

A single query moves through a funnel of retrieval and reranking stages, narrowing from roughly a thousand candidate passages down to one cited answer.

Query The input research question enters the pipeline.

Retrieval

Keyword Search

1,000

A broad, exact-match search across the full corpus surfaces the initial pool of candidate passages.

Semantic Re-scoring

1,000

The same candidates are compared to the query by meaning rather than wording — an exhaustive comparison against every candidate, not an approximate shortcut.

Combine Rankings

500

The keyword-based and meaning-based rankings are fused into a single ordered list.

Reranking Cascade

Learned Ranking

200

A trained model blends every signal gathered so far into a single, more reliable ranking.

Fine-Grained Matching

100

Passages are compared to the query piece by piece for closer alignment, rather than as whole documents.

Query & Entity Focus

80

Extra attention is paid to the query's key terms and named entities, blended with the earlier retrieval signal.

Joint Scoring

50

Each remaining passage is scored directly against the query as a matched pair — the most precise comparison in the cascade.

Final Reordering

20

A language model reviews the short list as a whole and reorders it for overall coherence.

Generation & Output

Evidence Selection

10

The top few passages are set aside as supporting evidence for the answer.

Answer Writing

A grounded answer is drafted from that evidence, sentence by sentence.

Rule Enforcement

Citation limits, length limits, and reference rules are applied before anything is saved.

Ranked List

Every judged passage, in order.

Cited Answer

The written, sourced response.

Validation

Both deliverables are checked against the required format before submission.

Answer Delivered

Every stage after the first search can be skipped on its own — the pipeline degrades gracefully rather than failing outright when a later stage isn't available.
